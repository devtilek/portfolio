# Портфолио Aktilek Korganbek

Тёмный адаптивный сайт на русском языке. HTML, CSS и JavaScript — без сборки и обязательных зависимостей.

## Открыть

1. Клонируйте репозиторий: `git clone https://github.com/devtilek/portfolio.git`.
2. Откройте папку `portfolio` в VS Code.
3. Откройте `index.html` в браузере или запустите `python -m http.server 8000` из папки проекта и перейдите на `http://localhost:8000`.

Для копирования email рекомендуется локальный HTTP-сервер или HTTPS: Clipboard API зависит от контекста безопасности браузера.

## Проверки

Установите Node.js 24 и выполните `node --check script.js` и `node --test`. Тесты проверяют локальные ссылки, ресурсы, доступность анимации и копирование email. GitHub Actions запускает их при push и pull request.

## Изменить

- `index.html` — тексты, проекты и ссылки.
- `styles.css` — цвета, адаптивность, анимации.
- `script.js` — появление секций и копирование email.

Шрифты Google Fonts загружаются при наличии интернета; без сети используется системный шрифт. Анимации учитывают настройку уменьшения движения. Фото и выдуманных ссылок на репозитории нет. Содержание основано на резюме, продолжительность опыта Cushpen Group обновлена до 1 года по вашему уточнению. Точная дата начала не указана.
