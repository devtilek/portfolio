# Портфолио Aktilek Korganbek

Тёмный адаптивный сайт на русском языке. HTML, CSS и JavaScript — без сборки и обязательных зависимостей.

## Открыть

1. Перенесите папку `front` на рабочий стол, если нужно.
2. В VS Code выберите **File → Open Folder → front**.
3. Откройте `index.html` двойным щелчком в Проводнике. Либо используйте расширение VS Code Live Server и **Open with Live Server**.

## Изменить

- `index.html` — тексты, проекты и ссылки.
- `styles.css` — цвета, адаптивность, анимации.
- `script.js` — появление секций и копирование email.

Шрифты Google Fonts загружаются при наличии интернета; без сети используется системный шрифт. Анимации учитывают настройку уменьшения движения. Фото и выдуманных ссылок на репозитории нет.
